
# AI Resume & Career Agent

## Overview
An AI-powered career assistance application designed to help users analyse their resumes, identify skill gaps, match job descriptions, and receive personalised career recommendations.

## Planned Features
- Resume Analysis
- Job Description Matching
- Skill Gap Analysis
- AI-Powered Career Recommendations
- Resume Improvement Suggestions
- AI Career Chat Assistant

## Technologies to Learn
- Python
- NLP
- Generative AI
- Large Language Models (LLMs)
- LangChain / LangGraph
- Streamlit
- Git & GitHub

## Project Status
Currently in the planning and initial development stage.
